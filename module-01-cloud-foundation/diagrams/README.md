# Diagrams

Every completed build in this course produces an architecture diagram as a required artifact. The method, and why it matters, is taught in Chapter 8's "Map it: your baseline as a diagram" section.

`foundation-starter.drawio` is the starter template for the module-01 foundation. The account, VPC, and subnet containers are already placed. Open it in draw.io (diagrams.net), enable the AWS shape library, and:

1. Place the seven foundation components inside the container each one truly runs in.
2. Label each with five words or fewer, plus the one value that matters.
3. Draw arrows only for real flows: data, identity, log delivery.
4. Fill the legend and the seven-slot controls strip along the bottom.

Commit two files to your portfolio repo: the `.drawio` source (it is text, it diffs, it lives next to the Terraform) and a PNG exported at 200 percent zoom with "include a copy of my diagram" checked. The PNG goes at the top of your README with a one-paragraph narration under it.

The placing is the learning. If you cannot place a component without looking back at the code, that gap is your re-read assignment.
